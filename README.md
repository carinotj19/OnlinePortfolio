# TJ's Online Portfolio

A responsive portfolio built with React and Vite.

## Features

- React-rendered portfolio sections for about, experience, projects, skills, and contact
- Responsive steampunk-inspired UI converted from the original static `index.html`
- Light and dark theme toggle with saved preference
- SVG machinery/gear animations
- GitHub Pages-friendly Vite base path

## Technologies

- React 19
- Vite 7
- CSS custom properties
- GitHub Pages-ready static build

## Project Structure

```text
index.html          # Vite HTML entry
vite.config.js      # Vite configuration
src/
  App.jsx           # Portfolio application
  App.css           # Portfolio styles
  main.jsx          # React entry point
  assets/           # Existing portfolio assets
```

## Setup

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

The production output is generated in `dist/`.
